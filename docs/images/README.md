FIX4 mantiene la conversión de colores y la composición y separa la transferencia
de LCD del productor de audio. Las imágenes no son fotografías de la pantalla
ni certifican la compatibilidad con todo el catálogo de juegos.

Las capturas PNG se guardan a su resolución de origen; la comparación de
texto está ampliada cuatro veces. El README puede ampliar las imágenes para
facilitar su lectura. No se incluyen los archivos ROM/DSK/CDT de esos juegos.

La galería actual utiliza únicamente las tres capturas FIX12 de la primera
fila. Las imágenes de versiones anteriores se conservan como historial.
La fotografía del equipo es el marco de los vídeos; el contenido de su LCD
procede de las grabaciones USB. [Procedencia de los vídeos](../media/README.md).
